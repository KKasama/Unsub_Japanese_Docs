# タイトルの購読

{% hint style="warning" %}
シナリオの作成は、[こちら](/unsub_guide_jpn/chtoriaru/shinariono.md)から作成をお願いいたします。
{% endhint %}

Unsubでは独自のCPU(Cost Per Use)を活用することによって、タイトル毎の購読を手助けします。祖場合、次のようなケースが考えられます。

* ビッグディールの解約を検討しており、アラカルト購読に切り替えた場合どの程度のコストが発生し、またどれくらいのアクセスが見込まれるのかを知りたい場合。
* よりよいビッグディールについて気になっていて、またビッグディールとアラカルト購読の比較を行いたい場合。
* すでにビッグディール契約を解除しており、アラカルト契約の正確な予測を知りたい場合。

タイトル単位での購読シュミレーションを、費用対効果を利用することで非常に簡単にできるようにしました。 ボタンひとつで、各ジャーナルタイトルを購読・非購読することができます。 -と＋の間に0がある、."Subscribed journals"と表示されたところをご確認ください。購読ジャーナルがゼロの場合、シナリオのヒストグラムの四角は全て灰色に表示され、購読している状態を示す青い四角は表示されません。

＋の箇所クリックすると1つのジャーナルが購読され、いちばん左下の四角が灰色から青色に変わるのが分かります。そのまま＋ボタンを押し続けると費用対効果の高い順にタイトルが購読され、-ボタンを押すとタイトルが非購読されます。

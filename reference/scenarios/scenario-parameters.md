# シナリオパラメータ

Unsubでは、貴機関の環境に合わせてシナリオをカスタマイズしたり、将来に関するさまざまな仮定を試したりするための多数のパラメータを提供しています。

パラメータの値はシナリオの一部として保存されます。パラメータの値は「パラメータ」メニューから変更できます。シナリオページのシナリオタイトル右側にあるコピーボタンを使用して、現在のパラメータ設定と同じ新しいシナリオを作成することもできます：

### &#x20;<a href="#h_68ea9b794f" id="h_68ea9b794f"></a>

### コスト <a href="#h_68ea9b794f" id="h_68ea9b794f"></a>

**タイトル単位の「コンテンツフィー」**

タイトル単位で購読を購入する場合に出版社が課すコンテンツフィーです（文献では購読に対して5.7%が示唆されています）。

デフォルト値：5.7%

**タイトル単位の購読コスト上昇率**

タイトル単位の購読価格における年間の上昇率の見込みです（文献では8%が示唆されています）。

デフォルト値：8%

### &#x20;<a href="#h_bb1971fa6a" id="h_bb1971fa6a"></a>

### ILL <a href="#h_bb1971fa6a" id="h_bb1971fa6a"></a>

**ILLの1件あたりのコスト**

貴機関におけるILLリクエスト1件あたりのコストです（文献では平均17ドルが示唆されています）。

デフォルト値：$17

**ILLリクエスト率**

ターンアウェイのうちILLリクエストにつながる割合です。弊社の広範な文献調査によると、5%は控えめな見積もりです。（注：ここでの「ターンアウェイ」とは、オープンアクセス、PTAの権利、またはこのシナリオにおけるタイトル単位の購読のいずれによっても充足されないすべての利用を指します。）

デフォルト値：5%

### &#x20;<a href="#h_d192405b0b" id="h_d192405b0b"></a>

### 充足手段 <a href="#h_d192405b0b" id="h_d192405b0b"></a>

**Bronze OAを含める**

充足手段の一つとしてBronze OAを含めます。Bronze OAとは、オープンライセンスなしに出版社サイトで無料公開されている論文です（Elsevierの「オープンアーカイブ」ジャーナルを含みます）。

デフォルト値：True（有効）

**査読前バージョンを許可**

Green OAにおいて、充足手段の一つとして投稿版（Submitted version）を含めます。投稿版とは、プレプリントなど、まだ査読を受けていないバージョンとしてリポジトリで公開されている論文です。

デフォルト値：True（有効）

**ResearchGateのコンテンツを含める**

充足手段としてResearchGateおよびその他の学術ソーシャルネットワークを含めます。

デフォルト値：True（有効）

### &#x20;引用と著者

**機関引用の重み付け**

貴機関の所属者による引用は、このジャーナルの利用に対して、この値に相当するダウンロード換算ポイントを加算します。一般的な設定値は10です。この場合、貴機関からこのジャーナルへの引用1件は、このジャーナルのダウンロード10回分に相当するものとしてモデル化されます。

デフォルト値：10

**機関著者の重み付け**

貴機関の所属者が著者として執筆した論文は、このジャーナルの利用に対して、この値に相当するダウンロード換算ポイントを加算します。一般的な設定値は100です。この場合、このジャーナルに掲載された貴機関所属者の論文1本は、このジャーナルのダウンロード100回分に相当するものとしてモデル化されます。

デフォルト値：100

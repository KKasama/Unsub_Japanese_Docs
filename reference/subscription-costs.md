# 購読料金

Unsubダッシュボードのご利用にはサブスクリプション（購読契約）が必要です。

弊社のコードは[オープンソース](https://github.com/ourresearch/get-unsub)ですが、サービスの維持・運用にはコストがかかります。購読料金によりそのコストを賄い、[非営利団体](https://ourresearch.org/)としての持続可能な運営を実現しています。

料金体系は、貴図書館の現在の年間資料費予算（印刷・電子のシリアル、書籍など）の規模に基づいています。

以下が料金区分です：



| **図書館資料費予算**（米ドル） | **費用**（米ドル） |
| ---------------------------------- | -------------- |
| $0 - 500,000                       | $500           |
| $500,000 - 1,000,000               | $1,000         |
| $1,000,000 - 1,500,000             | $1,500         |
| $1,500,000 - 2,000,000             | $2,000         |
| $2,000,000 - 2,500,000             | $2,500         |
| $2,500,000 以上                    | $3,000         |



貴図書館の資料費予算を正確に把握できない場合は、概算をお使いください。2つの区分の境界に該当する場合は、低い方の区分をお選びいただいて構いません。

予算が米ドル以外の通貨の場合は、現地通貨から米ドルに換算した上で、上記の表をご利用ください。過去1年間の平均為替レートを使用される方もいれば、当日のレートを使用される方もいらっしゃいますが、どちらでも問題ありません。

コンソーシアム（図書館共同体）としてのお見積もりをご希望の場合は、個別機関ではなく[コンソーシアム・ダッシュボード](pricing/consortium-dashboard.md)のページをご覧ください。

# ターンアウェイ（フルテキストにアクセスできなかったときの記録）

Unsubでは多くのパラメータを準備しており、その多くはユーザー権限で設定可能です。そのひとつにターンアウェイと呼ばれるもの（アクセスしようとしてもできなかった記録）があります。

COUNTER 5は、TR\_J2ファイル（"Journal Access Denied"）にターンアウェイデータが記載されています。

TR\_J2ファイルには、[こちら](/unsub_guide_jpn/yokuaru/notaitorugasarenainohanazedesuka.md)で説明されている例外に該当しない限り、No\_Licenseという指標を持つすべてのタイトルが含まれます。

上記のタイトルは、論文のフルテキストにアクセスしようとした際に抄録にリダイレクトされたケースであるという理由で含まれています。

Unsubではフルテキストにアクセスしたかどうかではなく読者が本当に読みたいと思うコンテンツを含めて計上することが本当のUsageと考えており、ターンアウェイの概念を導入しているのはそのためです。

※注意事項: COUNTER 4をご利用の場合、ターンアウェイのデータは含まれていないためカウントされません。 COUNTER 5をご使用の場合であればカウントされます。

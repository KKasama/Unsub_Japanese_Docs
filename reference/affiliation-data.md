# 所属データ

所属（アフィリエーション）とは、著者と論文を結びつける概念です。著者は論文の中で所属機関を申告し、その情報を取得することで、著者を所属機関を通じて論文と関連付けることができます。

Unsubにおいて所属データが利用される最も主要な場面は以下の2つです：

* 各タイトルのCost Per Use（CPU）計算に使用される加重総利用数
* APCタブ（予測機能には含まれません）では、所属データを使用して貴機関のAPC支出を推定します

その他にも、所属データは以下の用途で利用されています：

*
* asdf

所属データは[OpenAlex](https://docs.openalex.org/)から取得しています。

# コンソーシアム・ダッシュボード

Unsubは2019年11月に初めてリリースされました。初年度から数百の大学が購読データの理解と出版社との交渉にUnsubを利用しており、まさに待ち望まれていた製品であることが明らかになりました。

\
まだご覧になっていない方は、Unsubのアプローチを理解するために[Unsubのガイドツアー](https://vimeo.com/420183913)動画をぜひご視聴ください。

\
図書館コンソーシアムからは特に強い関心が寄せられています。多くのコンソーシアムが現在進行中の交渉にUnsubを活用しています。その大半は非公開ですが、ニューヨーク州立大学（SUNY）はUnsubの活用によりElsevierとの契約において60大学全体で年間数百万ドルの節約を実現したことを公表しています（[_Science_ 誌の記事](https://www.sciencemag.org/news/2020/07/tool-saving-universities-millions-dollars-journal-subscriptions)をご参照ください）。

\
コンソーシアム向けUnsubは、標準的なUnsub製品と同様にコンソーシアムの各メンバーがそれぞれ専用のダッシュボードを持ちますが、さらに全メンバーのデータを**合算して表示する追加のダッシュボードビュー**が加わります。この追加ダッシュボードビューは個別大学用のダッシュボードとほぼ同じ外観ですが、すべての数値（ダウンロード数、引用数、著者数）はメンバー大学全体の合計値となります。

\
多数の大学を抱えるコンソーシアムで、一部のメンバーだけをグループ化したい場合（例：医学部を持つメンバーのみ、あるいは小規模な大学のみ）、そのグループの合計値を把握することも可能です。\


このトップレベルのコンソーシアムデータにより、コンソーシアム全体として様々な購読オプションにおけるコストと充足の可能性を把握することができます。具体的には、ビッグディールを継続する場合の交渉材料として、またビッグディールからの離脱により経費を削減する場合にどのジャーナルを個別購読すべきかの判断材料として活用できます。

**料金**について：Unsubでコンソーシアムをセットアップする際の費用は、各メンバーの購読料金の合計です。コンソーシアム・ダッシュボードは無料で追加されます。例えば10メンバーの場合、[購入ページ](https://unsub.org/purchase)の表で各メンバーの資料費予算（おおよそ米ドルに換算）を確認し、10メンバーのUnsub年間費用を合計した上で、10%のコンソーシアム割引を適用した金額がコンソーシアム全体の費用となります。これまでのコンソーシアム顧客では、コンソーシアム組織が自身の資金から全額を支払うケースと、各メンバーに費用を按分するケースがあり、どちらの方法でも問題ありません。

**セットアップ**について：ほとんどのコンソーシアムでは、各メンバーが自身のCOUNTERデータをUnsubにアップロードします。一部のケースでは、コンソーシアムがすべてのCOUNTERデータを一元管理しており、そのデータを弊社にお送りいただければ、各メンバーのUnsubダッシュボードにバックエンドで反映いたします。基本的なダッシュボードの構築にはCOUNTERデータのみが必要ですが、PTA（購読終了後のアクセス権）の詳細な日付を記載したスプレッドシートをアップロードすることで、より正確な予測が可能になります。

Unsubは現在、Elsevier、Wiley、Springer Nature、SAGE、Taylor & Francisが発行するジャーナルの分析に対応しています。2021年半ばまでにすべての出版社に対応予定です。Unsubの利用料金は一律で、出版社ごとの追加料金は発生しません。

Unsubはコンソーシアムのメンバーの皆様、そしてコンソーシアム全体にとって非常に有用なツールであると確信しています。ご興味がございましたら、[support@openalex.org](mailto:support@openalex.org) までお気軽にお問い合わせください。

# 予測データが変わるのはなぜでしょうか？

定期的なデータアップデートは、Unsubの通常機能のひとつです。Unsubでは、ソースデータおよび計算の向上を行っています。

Unsubでは、細かいアップデートを繰り返し行い、表示データが急に大きく変化することはないように努めています。こうすることで、いつの時点でも正確なデータを提供できるようになっています。

また更新頻度は高くありませんが、より大きな変更に関する情報は[お知らせアップデートリスト](https://groups.google.com/g/unsub-announce)にサインアップいただけます。すべての変更内容については、[こちら](https://github.com/ourresearch/jump-api/blob/master/RELEASE_NOTES.md)にも記載されています。

# Unsubとオープンソース

Unsubとオープンソースに関して、2つの点を明確にしたいと思います。

### オープンソースだが、外部からのコントリビューションは受け付けていません <a href="#h_29cc10eeae" id="h_29cc10eeae"></a>

Unsubでは外部のコントリビューターからの貢献は受け付けていません。私たちは小規模なチームであり、コミュニティからのコントリビューションを管理するには時間がかかります。ただし、製品の改善のために、ユーザーからの機能リクエストやバグレポートはいつでも歓迎しています。

データベースBoltDBの作者が、新しいプロジェクトlitestreamについて、オープンソースではあるがコントリビューションは受け付けない理由を[説明しています](https://github.com/benbjohnson/litestream#open-source-not-open-contribution)。

### オープンソースだが、セルフホスティングはできません <a href="#h_761717ed48" id="h_761717ed48"></a>

多くのオープンソースプロジェクトは、誰でもどこでも（サーバー、ローカルマシンなど）実行でき、プロジェクトのオーナーと同じ結果を得ることができます。では、なぜオープンソースでありながらセルフホスティングができないプロジェクトがあるのでしょうか？

Unsubの場合、ユーザーが提供するデータや社内でキュレーションされたデータが重要な構成要素となっているため、ホスティングされたアプリケーションとしてのみ運用が可能です。

この状況は、[ソースアベイラブル](https://en.wikipedia.org/wiki/Source-available\_software)と呼ばれるプロジェクトに近いものです。

# UnsubはConsortium Managerとどう違うのですか？

Consortium Manager（CM）とUnsubの違いは、その名前に表れています。CMは既存の購読を**管理（manage）**するためのツールであり、Unsubは価値の低い購読を見つけて**購読解除（unsub**scribe）**し、コストを削減するためのツールです。

CMは「評価」「情報」「取得」「請求」「管理」の5つのステップをカバーしています。Unsubはそのうちの1つ、「評価」のみを行います。しかし、専門特化しているからこそ、Unsubは_評価においては_はるかに効果的です。実際、Unsubは[購読コストを数百万ドル規模で削減できる](https://www.sciencemag.org/news/2020/07/tool-saving-universities-millions-dollars-journal-subscriptions)ほどの成果を上げています。

![](https://downloads.intercomcdn.com/i/o/265016225/32ade22e671f06dcc1720196/Screen+Shot+2020-11-10+at+4.48.51+PM.png)

評価についてもう少し詳しく見てみましょう。購読の価値を評価するにあたり、CMは基本的な利用単価（CPU：Cost per Use）アプローチを使用しています。これは良い出発点ですが、Unsubはこれを大幅に拡張しています。

* CMは過去の利用データとコストデータを集計し、CPUが_これまでどうだったか_を示します。Unsubは同じデータを使って複雑な予測モデルを構築し、今後5年間のコスト（ILLコストを含む）、フルフィルメント、CPUを_予測_します。モデルのパラメータはカスタマイズ可能で、異なる前提条件に基づく複数の予測を作成できます。
* CMにとっての利用とは「ダウンロード」を意味します。それ自体は問題ありませんが、利用の一側面にすぎません。教員がジャーナルを引用したり、ジャーナルに論文を発表したりすることも、利用の一形態です。Unsubは教員の引用と著作をトラッキングし、ダウンロードとあわせてカスタマイズ可能な「重み」として組み込むことで、より正確な利用実態を把握できます。
* CMはオープンアクセス（OA）が利用に与える影響を考慮しません。多くのジャーナルでは、全利用の半分以上がOAによって無料で満たされる場合があります。Unsubはこれを考慮し、OAによって特定の購読をキャンセルしても教員のアクセスにほとんど影響がないことを示します。

まとめると、Unsubは単純なCPU計算では見落とされがちな大幅なコスト削減の可能性を明らかにします。出版社は長い間、図書館に過大な請求を行ってきましたが、Unsubはそれを初めて明らかにできる高度なツールです。Unsubに関する_Science_誌の見出しがすべてを物語っています：[「このツールは大学のジャーナル購読料を数百万ドル単位で節約している」](https://www.sciencemag.org/news/2020/07/tool-saving-universities-millions-dollars-journal-subscriptions)

要約すると、CMは多くの業務を処理します。それは素晴らしいことであり、有用なツールです。一方、Unsubは評価という1つの業務だけを担当します。評価に特化することで、その分野において非常に高い成果を上げることができるのです。

Consortium Managerは、購読の管理業務において時間を節約します。Unsubは、購読の再交渉において費用を節約します。

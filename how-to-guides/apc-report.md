
# APC(Article Processing Cost)ー論文投稿費レポート

APC（論文投稿費）レポートのタブは、機関画面で確認することができます。

<figure><img src="/files/oMEzADoebChRalvrdWLn" alt=""><figcaption><p>APCレポートのタブ</p></figcaption></figure>

ダウンロードボタンをクリックすると、スプレッドシートをダウンロードできます。

このレポートには、雑誌レベルでのAPC支出の推定値が掲載されています。この金額には、ゴールドおよびハイブリッドOAジャーナルに支払われるAPCが含まれています。Unsubでは責任著者の情報を保持していないため、この情報は推定値となります。著者として記載されている名前の人物誰もが等しく責任著者である可能性があると仮定し、推定値を算出しています。

APCの入手先について、詳細は[こちらの記事](/unsub_guide_jpn/unsubnoshikumi/apcnohadokokarashiteirunoedeshouka.md)をご覧ください。

このレポートに記載されている支出額の算出方法については、[こちらの記事](/unsub_guide_jpn/unsubnoshikumi/taitorugotonohadonoyounisurunodesuka.md)をご覧ください。


# パッケージ名・説明文の変更

> **※ 注意：** このページのスクリーンショットは英語版です。実際の画面は日本語で表示されます。


パッケージの作成時に、パッケージ名とパッケージの説明欄に記入することができます。より詳しい方法については、[パッケージ作成のチュートリアル](/unsub_guide_jpn/chtoriaru/pakkjino.md)をご覧ください。&#x20;

パッケージを作成した後にパッケージ名および説明欄の内容を変更するには、次の2つのうちいずれかを利用します。

### パッケージ・リストから

パッケージのリストから、お好きなパッケージの右側にある3つの縦並びの点のアイコンをクリックします。

<figure><img src="https://docs.unsub.org/~gitbook/image?url=https%3A%2F%2F2329511114-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FeIwtiPevlQYuy1bQ4x85%252Fuploads%252FtaObLB8JjCOv8vITeqqj%252Fchange-package-description-names.jpg%3Falt%3Dmedia%26token%3D821e3b21-d5f1-491a-b71a-bb8c4e72959c&width=768&dpr=3&quality=100&sign=c390a1dcee11afbd0a65ed9e40b87a66&sv=3" alt=""><figcaption><p>画面右側にある3つの縦並びの点をクリックし、パッケージ名や説明の編集ができます。</p></figcaption></figure>

Edit package nameもしくはEdit descriptionの箇所をクリックするとポップアップが表示されます。既に入力されているテキストを編集し、完了したら"Update"をクリックします。

### パッケージが既に選択された状態から

パッケージ自体の画面に入った状態で、「**Edit Details**」というタブを探します。

<figure><img src="https://docs.unsub.org/~gitbook/image?url=https%3A%2F%2F2329511114-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FeIwtiPevlQYuy1bQ4x85%252Fuploads%252FPeedFnIFXVg1dSxOqRsP%252Fchange-package-description-names-in-pkg-view.png%3Falt%3Dmedia%26token%3D5dff92c4-3e14-4ce8-a71d-a0cc7f144a4e&width=768&dpr=3&quality=100&sign=b3abfb28c3da3a0b7546a1f09621e097&sv=3" alt=""><figcaption><p>Edit Detailsのタブを見つけクリックします。</p></figcaption></figure>

右側にある鉛筆をクリックすると、既に入力されたテキストが表示されたポップアップが表示されます。テキストを編集して、「Update」をクリックします。

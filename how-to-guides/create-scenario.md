
# 新しいシナリオを追加する

> **※ 注意：** このページのスクリーンショットは英語版です。実際の画面は日本語で表示されます。


新しいシナリオは、追加またはコピーすることができます。様々なシナリオで異なるパラメータを設定して、また異なる購読形態を設定することでどのような形で購読するのが最善かを検討する材料になります。

シナリオを追加するには、一覧ページで「+New scenario」をクリックします。

すでにシナリオがひとつ作成されている場合は、[シナリオのコピー](/unsub_guide_jpn/gogaido/shinariowosuru.md)をすることをお勧めします。

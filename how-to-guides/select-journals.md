
# ジャーナルの選択

> **※ 注意：** スクリーンショットはできるだけ日本語を利用しておりますが、機能制限により英語版で提供している箇所もありますので、予めご了承ください。

Unsubダッシュボード（シナリオ画面）の右上には、検索/選択ボックスが表示されます。このボックスは、下記のような目的で利用することが出来ます。

1. 単数、もしくはカンマで区切られた複数のISSNに一致するジャーナルを検索できます。（入力例：「1878-8750,1876-2018,2468-6964」）表計算ソフトにセルの内容ををカンマで区切りでリスト生成する機能がありますので、そちらをご利用ください。例えば教員に調査を行って得られた情報など、Unsubでは設定できない要素に基づいて購読タイトルを決定する場合、この方法は特に有効です。
2. 「science」など、特定の文字列と一致するジャーナルを検索できます。検索対象は、ジャーナルのタイトルのみとなります。

以下は、検索により一致したジャーナルが選択されている状態の一例です。

* 検索により一致したジャーナルの総数がボックスのすぐ下に表示されます。
* ヒストグラム表示では、検索で一致しなかったジャーナルがすべて薄いグレーにフェードアウトし、一致したジャーナルのみを簡単にピックアップすることができます。
* テーブルビューでは、選択されたジャーナルのみがフィルターされ、一覧で表示されます。

カンマ区切りのISSNリストを使ってジャーナルを抽出します。検索ボックスの右側にある2つのアイコンは、[次の記事](/how-to-guides/batch-subscribe.md)で説明します。検索内容がどの項目とも一致しない場合、ヒストグラム上のタイトル（グレーのボックス）はハイライトされません。テーブル表示で検索テキストがマッチしない場合、以下のようなメッセージが表示されます。（クエスチョンマークの箇所をクリックすると、マニュアルの本ページに移動します）

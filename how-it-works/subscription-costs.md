
# タイトルごとの購読料はどのように計算するのですか？

Unsubの主要なデータソースは、各ジャーナルのタイトルごとの価格です。これは、ビッグディール以外でそのジャーナルを個別に購読することを選択した場合に、所属機関が実際に支払うことになるコストです。

ジャーナルタイトルの価格ソースは2つあります。また、Unsubが予測を微調整するために使用する2つの価格修正要素もあります。これらを組み合わせることで、あるジャーナルを購読する場合に、今後5年間に支払う年間価格を予測することができます。

### 価格ソース: <a href="#price-sources" id="price-sources"></a>

**1. カスタムアップロード価格:** [各ジャーナルの価格を簡単なスプレッドシートでアップロード](how-to-guides/upload-title-prices.md)することができます。アップロードされた価格は、デフォルトのリスト価格より優先されます。これは、デフォルト価格のないジャーナルに価格を提供する方法でもあります。

**2. 価格なし:** タイトルの価格をアップロードしていない場合、価格は不明です。その場合、モデルのコスト面にどのような影響を与えるか分からないため、このジャーナルは予測から省かれます。Unsubのシナリオには警告が表示されます。

### 価格修正要素: <a href="#price-modifiers" id="price-modifiers"></a>

価格が決まった後も、その価格が変化するケースは2通りあります。

**1. タイトルごとの購読コスト増加:** Unsubは、単にレポートするだけでなく、コストと実現を予測するように設計されています。そのためには、購読料金の時間的な変化を考慮するがあります。このパラメータは、毎年予想される価格上昇のパーセンテージを簡単に記述するものです。業界平均に基づくデフォルトは8%ですが、Scenarioメニューの "Parameter ➞ Cost ➞ タイトル毎の購読料増加 "で変更することができます。

**2. タイトルごとのコンテンツ料:** ジャーナルの購読料に影響を与える2つ目のパラメータとして、「タイトルごとのコンテンツ費用」があります。これは、出版社が購読料の見積もりに加えて請求することが多い追加料金（隠れた料金）であり、正確な費用見積もりを得るために考慮することが重要です。デフォルトでは5.7%に設定されていますが（Elsevierの最近の報告によるものです）シナリオメニューの "Parameters ➞ Costs ➞ Title-by-title 'content fee. "から編集することができます。

### すべてをつなぎ合わせる <a href="#putting-it-all-together" id="putting-it-all-together"></a>

*それでは、例えばJournal Xの場合どうなるのか見ていきましょう。*&#x307E;ず、タイトルごとに現在の定期購読価格を調べます。$1000の価格をアップロードしたとします。

5年予測の1年目は、1000ドルと5.7%の「コンテンツ料」57ドルの合計1057ドルを支払うと予測されます。

2年目は、購読料の8％増も加えて、1,080ドルとします。これにコンテンツ料（現在61.56ドル）を加えて、合計1,141.56ドルと試算しています。

3年目、4年目、5年目についても同様となります。最後に、5年分をすべて平均して、タイトルごとの購読の推定平均年間コストを算出します。
